# 아이펠 에이전트 과정 과제 제출

```text
[도메인 맥락]
나는 크로스핏 박스 운영 및 코칭 도메인 3년 차이고, 매일 네이버 카페(크로스핏051)에 '오늘의 와드 기록'과 '내일의 와드'를 올리는 작업을 자동화/정리하고 싶습니다.

[네 동작 분석]
1. 분해:
   - 와드 기록 올리기: 칠판 기록 사진 촬영 → 네이버 카페 앱 실행 → 크로스핏051 카페 접속 → Record 게시판에 날짜 제목으로 사진 글 작성
   - 내일의 와드 올리기: 구글 시트 열기 → 내일 날짜의 와드 복사 → 메모장에 붙여넣고 다시 복사(서식 정리) → 네이버 카페 앱 실행 → 크로스핏051 카페 접속 → WOD 게시판에 날짜 제목으로 글 작성
2. 패턴:
   - 매일 같은 것: 앱 실행, 카페 접속, 게시판 선택, 글쓰기 절차, 제목 형식
   - 매일 다른 것: 제목의 날짜, 기록 사진, 구글 시트에서 가져오는 와드 내용
3. 추상화:
   - 입력(사진 또는 구글 시트의 와드) + 날짜 → 정해진 게시판에 "[날짜] 제목 + 본문" 형식의 글 1개 게시
   - 두 작업은 '입력 소스'와 '게시판'만 다르고 구조는 같은 하나의 "일일 게시글 발행" 작업이다.
4. 알고리즘:
   1 매일 정해진 시간에 실행
   2 내일 날짜를 계산해 구글 시트에서 해당 행의 와드를 읽어 서식을 정리
   3 전날 와드와 비교해 중복 동작이 있으면 코치에게 먼저 알림, 없으면 다음 단계로 진행
   4 "[날짜] WOD" 제목으로 WOD 게시판에 게시
   5 수업 후 코치가 칠판 사진을 지정 폴더나 채팅에 올리면 "[날짜] Record" 제목으로 Record 게시판에 게시
   6 게시 성공/실패 결과를 코치에게 알림

[출력 요구]
네이버 카페 게시판에 매일 자동으로 올라가는 게시글 형식(날짜가 들어간 제목 + 와드 본문 또는 기록 사진)으로, 한국어로.
자동 게시가 어렵다면 복사해서 바로 붙여넣을 수 있는 게시글 초안과 대안 자동화 방법을 함께 제시.

[검증 기준]
크로스핏051 네이버 카페에 가입한 회원이 "카페에서 내 기록을 쉽게 찾아볼 수 있고, 내일 와드가 무엇인지 한눈에 알 수 있다"라고 평가할 것.
```
